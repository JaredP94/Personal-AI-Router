### Effective Tracing and Privacy Controls

**Runtime work is still required.** The UI persists enabled/endpoint/payload
settings, but proxy providers read startup environment variables. Defaults are
tracing enabled, `localhost:4317`, payload capture off. Collector advertisements
do not select exporter destinations. Decide and implement the effective
configuration contract, then test UI → broker → proxies end to end, including
restart, disabled tracing, payload opt-in/off, and actual collector destination.

The supplied Phoenix configuration exposes ports `6006` and `4317` without
loopback host restrictions or configured authentication/TLS; export is plaintext.
Decide the secured deployment/remote-collector policy. Verify header/content
capture and named-volume retention/deletion. A documentation warning does not
implement these privacy controls. See [Security](../SECURITY.md#opentelemetry-and-phoenix-current-limitations).

Source anchors: each proxy's `telemetry.go`, `services/shared/telemetry/`,
`services/nvpair-node-settings/manager.go`,
`services/nvpair-ui-broker/broker_telemetry.go`, and
`docker-compose.telemetry.yml`.

### Scheduling Telemetry and Idle Sampling

Scheduler consumers retain foreground node-info reads. Letting manual probes
(10 seconds) read a cached idle GPU sample (also 10 seconds) can exhaust most of
the scheduler's 10-second freshness budget before the next observation arrives.
Background reads remain available for explicitly hidden UI polling, but the
scanner/manual consumers must not enable unattended sampler backoff until
collection/delivery/freshness timing is coordinated and tested. The earlier
profiling improvements from scheduler-background sampling must not be reused
as measurements of this corrected release tree.

### Desktop Relay Envelope Validation

Go codecs enforce notification `epoch`/`seq` stamps and reject them on
requests/responses. The desktop `JsonRpcSubprocess.handleStdout()` currently
extracts optional stamps but does not reject every malformed/missing envelope.
Keep client and worker versions matched; decide whether the desktop should
implement the same terminal validation and add regression coverage before
claiming universal protocol rejection.
